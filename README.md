# 一案四时 · 清供 DIY 数字案几

一个纯前端的 Three.js 清供布置原型。六类器物均由 Three.js 几何体程序化构建；布局保存在当前浏览器的 `localStorage`，无需账号或后端。

## 运行

建议 Node.js 20.19+ 或 22.12+。在项目根目录执行：

```bash
npm install
npm run dev
```

打开终端显示的本地地址（默认 `http://127.0.0.1:5173/`）。生产构建：

```bash
npm run build
npm run preview
```

本次开发环境的 Node 运行时未附带 npm，因此实际使用 pnpm 安装依赖并执行同一套脚本；`npm` 命令使用标准 `package.json` 脚本。若也使用 pnpm，可执行 `pnpm install`、`pnpm run dev`、`pnpm run build`。

## 操作

- 点击左侧器物卡片添加；也可直接把卡片拖到桌面指定位置。相同器物可以重复添加。
- 在三维场景中按住器物拖动。拖动空白区域旋转视角，滚轮缩放。
- 点击器物后，右侧可调整垂直轴旋转和大小，或复制、删除、重置该器物。
- 右侧可加载三套预设、清空案几。顶部可恢复初始视角、保存布局。
- “生成我的清供图”下载 1800×1125 PNG，仅包含三维场景，不含操作面板。

## 源码结构

| 文件 | 作用 |
| --- | --- |
| `src/scene.ts` | 场景、书斋背景、木质案几、相机、光照、渲染与尺寸响应 |
| `src/models.ts` | 六种程序化三维器物的独立构建函数 |
| `src/main.ts` | 页面、统一物件实例管理、选择、拖拽、编辑与 PNG 导出 |
| `src/presets.ts` | 三套清供布局数据 |
| `src/storage.ts` | 布局的本地保存与恢复 |
| `src/types.ts` | 器物类型和统一数据结构 |
| `src/style.css` | 页面样式与响应式布局 |

## 当前限制

- 器物模型是统一风格的程序化造型，并非扫描级写实模型。
- 拖拽允许有意重叠摆件；自动添加会尽量寻找空位，但不会强制做物理碰撞检测。
- 保存只作用于当前浏览器和站点地址；更换浏览器或清除站点数据会失去保存的布置。
- 交互以桌面鼠标为主要验收目标；窄屏布局可浏览和点击，触控体验仍可继续优化。

可继续扩展器物材质细节、场景光照预设与更精确的碰撞辅助；这些不影响当前的三维摆放和继续编辑功能。
